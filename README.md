**memory-game task**

**Описание приложения:**
- игра реализована в виде набора карточек с числами от 1 до 8
- в процессе игры нужно находить карточки с одинаковыми числами
- если за один ход найдены две одинаковые карточки, то они остаются открытыми
- после открытия всех карточек выводится окно с результатми
- работа приложения рассчитана на ширину экрана не менее 768px

**Запуск приложения**
- перейти по ссылке https://kchrgn.github.io/memory-game
- игра начнется автоматически
- для запуска игры заново нажать кнопку "Новая игра"

**Запуск приложения локально:**

- клонировать репозиторий локально
- перейти в ветку memory-game
- установить расширение Live Server для VS Code
- в правом нижнем углу нажать Go Live
- откроется страница в браузере с локально запущенным приложением - можно играть
